# rag-example-project

A python project to test out a using RAG with an LLM.

The goal is to write a python script to store a test documents embeddings in a postgres vector DB and then use the RAG data to inform questions for an LLM.

Additionally to use a front end to visualize the models emebddings in a 2 dimensional reduction as well as attempt to view the embeddings through a coloring method using HSL to represent the data.

The project will use docker compose to run the application and the database, the LLM and emebbedding model will use a local model hosted on the network.
